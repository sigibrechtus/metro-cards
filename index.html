Aide

Ajouter Cartes Métro Paris à l’écran d’accueil crée une icône qui ouvre le site dans une fenêtre proche d’une application. Ce n’est pas une application native ni une copie indépendante du site.

iPhone ou iPad

  1. Ouvrez l’adresse du site dans Safari.
  2. Appuyez sur Partager (le carré avec la flèche vers le haut).
  3. Choisissez Sur l’écran d’accueil / Add to Home Screen.
  4. Activez Ouvrir comme app web si l’option apparaît, puis appuyez sur Ajouter.
Instructions Apple

Android

  1. Ouvrez le site dans Chrome.
  2. Appuyez sur ⋮, puis Installer l’application, Installer et créer un raccourci ou Ajouter à l’écran d’accueil (le libellé dépend du téléphone).
  3. Confirmez l’installation ou l’ajout du raccourci.
Instructions Chrome pour Android

Ordinateur

Dans Chrome, ouvrez ⋮ → Caster, enregistrer et partager → Installer la page comme application (ou utilisez l’icône d’installation dans la barre d’adresse). Dans Edge, ouvrez … → Autres outils → Applications → Installer ce site en tant qu’application.

Instructions Chrome · Instructions Edge

Les cartes restent synchronisées en ligne

Connectez-vous au même compte dans l’app sur chaque appareil. Les cartes sont enregistrées dans Supabase et se synchronisent entre appareils avec Internet. L’icône sur l’écran d’accueil ouvre le même site; elle ne crée pas un nouveau compte et ne désactive pas la synchronisation. Sans Internet, les modifications restent sur cet appareil. Au retour de la connexion, l’app vérifie d’abord la version en ligne. Si un autre appareil a enregistré entre-temps, la version en ligne prévaut et remplace les changements locaux non synchronisés. L’option Rester connecté permet de retrouver votre session sur cet appareil.
